# Haidar System — Visual Direction

## Character

- Technical
- Calm
- Precise
- Modern
- Systems-oriented
- Experimental but credible
- Minimal

## Visual Language

Prefer:

- System diagrams
- Architecture maps
- UI fragments
- Product screenshots
- Structured typography
- Clean technical compositions
- Process visualizations

Avoid:

- Generic stock imagery
- Excessive AI-generated “future tech” visuals
- Overly noisy layouts
- Fake dashboards or fabricated results presented as real
- Visual decoration that obscures the idea

## Design Principle

> **Clarity before decoration.**

The visual identity should make the audience feel that there is a thoughtful system behind the work.

## Future Brand Kit

When the visual identity is mature enough, formalize:

- Logo usage
- Typography
- Color system
- Spacing/grid
- Image treatment
- Diagram conventions
- Social post templates

Do not over-invest in the brand kit before the positioning and content system have been validated.
